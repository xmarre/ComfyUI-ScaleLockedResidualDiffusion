# ComfyUI Scale-Locked Residual Diffusion v1.3.2

## Krea 2 Spectrum controls

- `sa_planner_spectrum_forecasts=false` now runs the planner natively for all Spectrum-supported samplers, including ER-SDE and Euler. In spectral-progressive sampling it applies to the first segment. Later passes retain their own forecasting settings.
- The historical input name is preserved for saved workflows. The independent `sa_spectrum_forecasts` switch continues to control whole-run native execution for SA-Solver and SA-Solver PECE.
- With [Spectrum Krea 2 v0.2.2](https://github.com/xmarre/ComfyUI-Spectrum-Krea2/releases/tag/v0.2.2) or later, use Spectrum's `extrapolation_guard_scope` to choose the planner, high-resolution passes, or both. The planner's native-only switch works with Spectrum v0.2.0 or later.

## Patch-lattice diagnostics

Handoff diagnostics now report a repeating 2×2 latent pattern's coherence, amplitude, signed modes and similarity to the planner. The experimental `patch_lattice_correction=final_latent` option subtracts the measured constant offset from the final output and denoised output. It defaults to `off`. It runs after sampling and leaves the planner output unchanged.

One real-checkpoint run logged the correction reducing the final latent's coherence from 0.0901 to 0.0000 at the displayed precision. This measures the removed latent component. The underlying source of the pattern and decoded visual fidelity across checkpoints remain open. [Patch-lattice diagnostics guide](https://github.com/xmarre/ComfyUI-ScaleLockedResidualDiffusion/blob/v1.3.2/docs/patch-lattice.md)

## Verification and upgrade

Native ComfyUI CPU integration verified that a 14-step ER-SDE planner produced zero forecasts with the planner switch off and matched a Spectrum-free baseline bit for bit. A real-checkpoint ER-SDE run with guard scope `planner_only` recorded five guarded planner forecasts and one forecast in each of two unguarded refinement passes. Reproducible GPU speedup has not been measured.

Use ComfyUI Patcher to update Scale-Locked and Spectrum to the released versions. Restart ComfyUI after updating.

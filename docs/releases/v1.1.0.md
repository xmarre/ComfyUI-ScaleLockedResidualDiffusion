# ComfyUI Scale-Locked Residual Diffusion v1.1.0

## Added

- **Krea 2 Turbo Flow-Aligned Regenerate [Experimental]**: a low-resolution planner and full-prediction composition lock for native Krea 2 Turbo, using CFG 1, Euler/simple and flow shift 1.15.
- Closed-form target handoff for unmasked flow-Euler schedules: locked high-resolution steps do not run the target denoiser.
- Patch-phase Gaussian noise coupling, including noninteger planner-to-output scale factors.
- Restart-based resolution ladder for large output canvases, with automatic area-growth limits or explicit intermediate megapixels. Intermediate stages each finish their image before the next stage re-noises and refines it.
- **Resolution Selector (Uncapped)** with the built-in aspect ratios, rounding, preview where available and explicit per-axis maximum validation.

## Changed

- The experimental Krea 2 node now defaults both post-release frequency-band lock strengths to zero to avoid doubled contours and softened fine detail. Existing saved workflows retain their stored values; adjust them manually if necessary.
- The generic Scale-Locked Residual samplers and their defaults remain unchanged.

## Validation

- 28 CPU numerical tests passed on the release candidate, including patch-noise invariants, composition-lock trajectory algebra and stage parsing. Small random-weight ComfyUI integration exercises native execution, schedule handling and both Krea 2 image latent layouts.
- Limited real-checkpoint comparisons have shown clean examples near 4 MP and for a 4096² multi-stage image. These individual observations are not a systematic quality study.

## Limitations

- Krea 2 Turbo regeneration above its normal native resolution is **experimental**. Artifacts, excessive VRAM use and slower wall time are possible. There is no general image-quality or speedup claim.
- The resolution ladder requires native flow-Euler sampling without masks or manifold correction. Each intermediate stage incurs additional post-release denoiser evaluations.
- Other checkpoints, solvers and custom-sampling integrations should use the generic Scale-Locked nodes.

Install the released repository through ComfyUI Patcher or the ComfyUI registry and restart ComfyUI. No manual repository operations are necessary.

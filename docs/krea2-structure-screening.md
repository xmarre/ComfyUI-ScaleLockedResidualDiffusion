# Krea 2 structure screening

Select **Regeneration mode → trajectory_auto_observe** to run the same schedule and model calls as `trajectory_auto` and record structural evidence. Existing `trajectory` and `trajectory_auto` workflows keep their previous behavior. The observer covers the first unlocked high-resolution refinement, including a single-stage run, and every later completed-latent handoff.

## What the logs measure

A stage uses the completed planner or preceding completed stage as its reference. The observer compares the actual enlarged start when present, each observed unlocked outer-step clean estimate, and the completed output. Fully locked steps do not generate independent target predictions. The first stage has no completed-latent enlargement to score.

- The comparison grid preserves the source aspect ratio and fits inside both the source grid and a 128-cell longest-axis cap. The second scale halves this grid. The analysis reports `grid_too_small` when the shorter side cannot support a full gradient patch at both scales.
- The two-scale feature is the horizontal and vertical gradient in each internal Wan 2.1 latent channel. Pooling precedes the channelwise affine normalization of output-space reference and completed samples. Outer-step estimates arrive in internal space already.
- Overlapping 8-cell patches compare gradient directions using normalized correlation. For each patch the best common match within a one-cell displacement per axis accounts for small translations. Added and missing scores use unmatched gradient energy from the candidate and reference, respectively. The residual fraction is `1 - corr²` for positive correlation, with an energy floor based on the reference's average patch energy. `gradient_energy_ratio` separately reports how much gradient energy survived the comparison. Strong evidence requires inspecting both directions and both scales.
- The noise-level check uses `variance(reference) * ((1-sigma)/(sigma*noise_scale))²` as a conservative input-SNR proxy, with unit SNR as the point where signal variance matches native noise variance. The estimate uses the pooled reference and the unattenuated native noise scale. It is neither an estimate of prediction error nor a measure of local semantic confidence. Blank, near-constant and nonfinite items can be marked unavailable independently within a batch.
- `repeated_added` is the shared added evidence across two adjacent eligible callbacks. The first candidate, low-SNR pairs and gaps in a long schedule have no repeated evidence. Two observations support a persistence check, with no claim of statistical independence.
- `preferred_step` is the measured prediction that best preserves shared-grid gradients, considering both directional losses and penalizing lost gradient energy. Ties prefer lower sigma. It can be empty or be the final observed prediction. It is a diagnostic ranking and does not select the output. Texture below the comparison grid is unscored. Fine texture that survives pooling, valid structural changes, blur and heavily textured regions can still affect the scores.

Every stage emits a JSON record with normalized `peak_box_xyxy` coordinates, using the top-left origin, and per-image evidence. The cap is 32 prediction summaries per stage, including the first two and last unlocked steps. The observer keeps only compact maps and the previous candidate's added evidence. It uses no decoder, VLM, additional denoiser calls, or sampler state copies. With GPU-resident reference latents, compact summaries transfer to the host at stage completion. If the previous stage and current sampler use different devices, only the reduced grid transfers between them.

## Research and integration choices

[StructSR](https://arxiv.org/pdf/2501.05777) screens early predicted clean samples using image-domain SSIM. Its [StableSR implementation](https://github.com/LYCEXE/StructSR/blob/0765b0fade20fffcd2937d946b803525cddcc1e6/ldm/models/diffusion/ddpm.py#L2504-L2610) decodes with the low-resolution image's encoder features, compares the first batch item to the already resized low-resolution RGB input, and keeps the candidate with the highest SSIM over the initial 30% by default. This uses StableSR's learned, timestep-aware structural encoder and feature-wrapped decoder.

| Mechanism | What the reference does | Krea 2 implications |
| --- | --- | --- |
| Structure-Aware Screening (SAS) | Selects an early clean prediction by SSIM to the observed low-resolution input. | The planner is generated, so screening reports local correspondence and changes without treating the source as ground truth. A two-step suffix is scored using only its two actual callbacks. |
| Structure Condition Embedding (SCE) | The paper combines the original and structure-conditioned model predictions with weights `1-Smax` and `Smax`. The released StableSR code adds the second evaluation at the screening boundary, in its single-conditional branch. | Krea 2 has reference-token conditioning, but its meaning and resource cost differ from StableSR's learned structural encoder. Adding or replacing tokens changes the operator, token layout, and attention cost. Injecting a condition mid-session needs a new Spectrum contract. |
| Image Details Embedding (IDE) | Blends the chosen clean latent into later reconstructions with a weight proportional to maximum SSIM and remaining time, then constructs the DDPM posterior. | Krea 2 uses a flow clean prediction `x0 = x - sigma * v`. Substituting a clean estimate changes the solver's derivative and multistep history. A generated planner also supplies no calibrated degradation likelihood. Prior low-band projection caused duplicate anatomy. |

Local normalized correspondence follows the general registration idea of comparing aligned structures, as in [Lucas–Kanade](https://ijcai.org/proceedings/1981/127), and the structural emphasis of [SSIM](https://utw10503.utweb.utexas.edu/publications/2004/zwang_ssim_ieeeip2004.pdf). The method here is a discrete bounded search on latent gradients. SSIM is calculated in neither pixel nor latent space by this observer.

[VHA](https://arxiv.org/html/2610.25770v1) asks questions in both directions across ground-truth and super-resolved images, covering missing details and unsupported additions. The [official code](https://github.com/dhryougit/Hallucination-Assessment) scores answer support with a vision-language model, and VHA+ learns a score from paired DINOv3 CLS embeddings. Both are designed around ground-truth comparisons. With a generated planner, fine details may be unanswerable at source resolution. These tools may assist offline human review when questions restrict themselves to visible source evidence. They are unsuitable as step-level gates here.

The native sampler callback is downstream of CFG and the Scale-Lock guider. It receives the clean estimate already computed for the outer solver step. Spectrum can forecast the underlying feature evaluation, and its callback intentionally runs outside the forecasting context. The report does not infer per-step provenance. Compare the same run's Spectrum receipt or disable forecasting for a native-only localization control. The SA-PECE corrector is a separate evaluation after the callback. Compare the completed sample to catch changes absent from the predictor trace.

### Intervention gate

| Candidate intervention | Numerical and quality implications |
| --- | --- |
| Modify a prediction before the solver consumes it | A coherent CONST change would supply `x0 + delta` everywhere the solver uses that prediction, equivalent to `v - delta/sigma` at positive sigma. Editing the callback tensor risks aliasing native history, and a modification after a PECE predictor callback cannot safely pretend to correct the separate corrector. A score-derived displacement needs decoded validation before it can define a correction. |
| Enforce source consistency as an inverse problem | [DPS](https://arxiv.org/abs/2209.14687) and [DDNM](https://arxiv.org/abs/2212.00490) rely on an observation operator and an observed measurement. A preceding generated latent is not a calibrated observation of the desired high-resolution image. Local gradient changes alone cannot supply a likelihood or justify projection. |
| Accept an alternate candidate at a completed stage boundary | A boundary keeps native solver history intact. A selected earlier prediction can still be incomplete or blur valid detail, and a lower-resolution fallback or replay changes detail or cost. The current metrics cannot justify replacing a completed stage. |

Correction remains disabled pending real-checkpoint evidence. No guidance weights, extra steps, retries or new controls are needed to obtain the screening evidence.

## Decoded acceptance procedure

Run `trajectory`, `trajectory_auto` and `trajectory_auto_observe` with the same seed, checkpoint, LoRAs, prompts, solver, resolution ladder and patches. Keep Spectrum bootstrap disabled. A deterministic observation run should match the auto run. Use `handoff_diagnostics=log_and_save_latents` for localization. The existing diagnostic node can decode the planner, enlarged inputs, outer-step predictions and completed outputs with the same VAE. Inspect the reported regions at native resolution.

- A defect present in the planner predates all target refinements. A change first visible in the first unlocked prediction or the first completed refinement is outside the automatic restart policy.
- A change already visible in an enlarged start can be compared against the prior completed stage and the alternative enlargement method. A change first visible in a later prediction or completed sample points to that refinement. If it appears only in the completed sample, compare the solver, including its corrector or stochastic behavior where applicable.
- Include valid texture, identity, anatomy and text controls. Check whether peaks identify independently labeled defects across several seeds and whether valid added detail produces similar scores. Compare selected native-only runs to isolate forecast dependence. Test comparable within-range resolutions before attributing a defect to inference above the checkpoint's nominal range.
- Measure observer overhead with latent dumps disabled, using repeated warm GPU runs, per-stage timings, peak VRAM and backend receipts. A future active mode requires a separate matched-seed comparison demonstrating suppression without losing useful detail.

A low score cannot establish image fidelity, and CPU numerical parity does not establish decoded image quality.
